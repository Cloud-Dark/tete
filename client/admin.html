Who can do what

Public

  • Up to 25 MB per file
  • Files live at most 7 days; no "Never"
  • Counted against the storage quota

Admin

  • No size limit from TETE for files without a password (streamed)
  • Any lifetime, including Never
  • Not counted against the quota

The real ceiling for admin uploads is set by the storage provider (its per-object limit on your plan) and by Cloudflare's request size limit. Files with a password are processed in memory and stay at 25 MB.
